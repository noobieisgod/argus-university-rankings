# Rights-first publication

The initial release is prepared from locally verified, unchanged ranking inputs. Those four original JSON files and all workbooks/research archives stay out of public Git history.

## Gates

1. Verify photo source, credit, reuse terms, required notices, adaptation conditions and the selected local-file checksum for all 237 images.
2. Review public exposure of publisher observations, publisher ranks, ARGUS-derived results, admissions, source text, metadata and fixtures. Keep raw publisher inputs, excluded tables and private review records out of both public branches and deployed artifacts.
3. Reconcile README with the finalized methodology and actual display behavior. User-reported acceptance is not publisher verification. SAT/GPA never score.
4. Demonstrate a real unattended local checkpoint, GitHub-authenticated documentation push and later recovery before calling the background workflow verified.
5. Validate the complete static release, including project-path links, assets, all 249 routes, ranking membership, NR states, interactions and desktop/mobile views.

GitHub Pages serves the reviewed minimal release. The manually dispatched release workflow accepts only the exact approved publication commit and matching manifest. The deployment workflow does not need the excluded raw inputs.

## Batches and recovery

Text pushes are limited to three changed files and 750 added/deleted lines combined. Photo-only pushes are limited to 20 images. Use actual timestamps, meaningful messages and verified authorship. No force-push or fabricated history.

Record file hashes and successful remote commit SHAs. Verify an uncertain remote result before retrying. Unexpected remote changes, failed authentication, altered approved bytes or ambiguous runner locks stop writes. Do not overwrite unrelated work.

## Reproduction

The public source does not contain proprietary input datasets. Source syntax and public artifact integrity can be checked independently, but full numerical reproduction requires the private hash-verified inputs and local archive checks. A public clone is not represented as a self-contained data package.

The generated site lives on the separate `gh-pages` publication branch. Excluding raw JSON does not automatically clear HTML or derived results. Source attribution, access to a source, and the code license must not be represented as publisher reuse permission. Preserve rankings and institutions when reviewing future changes.
